# test-Work-Log
Work Log
工作记录
一个简洁实用的纯前端工作记录应用，单文件 index.html，数据存储在浏览器 localStorage 中，无需后端即可运行。

preview

功能特性
日历视图
按月浏览日历，快速查看哪天写了记录、哪天有任务
有记录的日期底部显示绿色横条
有待办任务的日期右上角显示橙色圆点，全部完成后变绿色
当天日期高亮为蓝色渐变
鼠标悬浮日期可预览当天任务和记录（桌面端）
长按日期可预览（手机端），短按进入详情
右键日期可快速添加任务或记录（桌面端）
工作记录
点击日期进入详情页，支持创建多条记录
富文本编辑：加粗、斜体、下划线、删除线、无序/有序列表
截图粘贴：直接 Ctrl+V 粘贴截图到编辑器
图片上传：工具栏图片按钮选择本地图片插入
每条记录自动带时间戳
支持为记录打标签，标签可自由创建
长文本支持滚动，写再多也不会撑开页面
任务管理
支持创建单次任务（指定日期）和重复任务（每天/每周/自定义间隔）
任务自动出现在对应日期的日记页顶部，作为待办清单
点击圆圈打勾完成，未完成的任务在日历上橙色标记
任务可随时编辑、暂停/启用、删除
历史回顾
按月切换浏览过去的日记
支持关键词搜索（搜标题和内容）
支持按标签筛选
搜索结果点击直接跳转到对应记录
标签管理
写日记时可直接输入新标签
标签管理页查看所有标签及使用次数
支持删除不再使用的标签

数据说明
所有数据保存在浏览器 localStorage 中：

worklog_entries_v1 — 工作记录
worklog_tasks_v1 — 重复任务
worklog_onetime_tasks_v1 — 单次任务
worklog_tags_v1 — 标签
worklog_completions_v1 — 任务完成状态
注意：清空浏览器数据会导致记录丢失，建议定期备份上述 localStorage 键值。
